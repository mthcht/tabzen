Welcome to TabZen

You're all set with sensible defaults — tabs will auto-suspend after 30 minutes of inactivity. Browse through the sections to fine-tune. Everything is stored locally; nothing is sent anywhere.

Whitelist & blacklist

Match URLs by domain, glob, contains, exact, or regex. Whitelist entries are never suspended; blacklist entries are forced (overrides "never suspend" rules).

Whitelist

domain — matches the host and all subdomains (e.g. github.com) · contains — substring of the full URL · exact — exact URL match · glob — wildcards: * any chars, ? one char · regex — JavaScript regular expression

    Blacklist (force-suspend)

    Use sparingly — these matches ignore the "never suspend" guards (except internal/active).

      Per-domain rules

      Override the base timer or behaviour for specific URL patterns or named tab groups. Rules are evaluated top-down; the first match wins.

            About

            TabZen runs entirely on your machine. No telemetry, no analytics, no remote config. Storage uses chrome.storage.local; tab activity tracking lives only in this browser session.
